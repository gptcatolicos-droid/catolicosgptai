PAQUETE ESTABLE V8 - ROLLBACK CONTROLADO

Usa este paquete para volver al servidor estable anterior.

Sube/reemplaza en el root del repo solamente:

1. server.js
2. recursos-pdf-module.js

Este paquete:
- NO incluye carpeta data.
- NO incluye archivos JSON de contenidos.
- NO borra infografias, blogs, videos, podcasts, santoral ni recursos PDF.
- Conserva soporte de recursos PDF, covers y botones de compartir.
- Conserva enlaces de PDF con target _blank para abrir en nueva ventana cuando el navegador lo permita.

Importante:
- No mezclar con el paquete v7 de arranque blindado.
- Este v8 debe reemplazar el server.js que quedo en GitHub tras el deploy fallido.

Si el deploy falla incluso con este paquete, abre "Ver en el Explorador de registros"
en Google Cloud y copia el error de Node.js. La pantalla de Cloud Build solo muestra
el mensaje generico del puerto 8080, no la causa real.
